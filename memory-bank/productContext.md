# Product Context

The application replaces fragile, manually maintained Excel helper columns used to count AUSCO Presidency ranked votes. Election officers download Google Forms responses and need an auditable result that follows the voting rules consistently.

The user experience prioritises clarity and privacy: choose a downloaded spreadsheet, confirm the detected columns and executive password, then inspect a ranked result. No Vote responses, invalid responses, executive-doubled votes, and non-matching supplied keys are visible as separate categories so the count can be independently checked.

All processing occurs in the user's browser. The executive password is neither saved nor exported.
